# Ember Duel

An original elemental card battler — you versus the Ember Imp. Both duelists
start at 30 HP; mana starts at 1 and grows by 1 each turn (max 10). Play
Strike, Guard, Siphon and Surge cards across four elements — Fire/Ember 🔥,
Water 💧, Gale 🌀, Stone ⛰️ — and trigger an element combo by playing two
cards of the same element in one turn. The Imp plays back with a readable
strategy: it takes lethal when it can, guards when it is hurt, and otherwise
plays its best-value cards.

## Run it

Serve the `game/` folder with any static server and open `index.html`:

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 — no build step, no network requests, no
libraries. Click a glowing card to play it, press Space (or End Turn) to pass,
1–9 to quick-play a card, M to mute, R to restart.

Screenshot scenes (used for the entry images): `?shot=title|table|win|loss`
with an optional `&seed=N` for a repeatable deal.
